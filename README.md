**AINotes** — легкая фоновая утилита для Windows (10, 11), которая живет в системном трее и превращает выделение любого текста, кода, файлов и папок в мгновенную базу знаний с быстрой вставкой прямо в курсор.

> Это не громоздкий комбайн для ведения дневников. Суть утилиты — в один клик сохранить нужный сниппет кода, команду терминала или путь к папке проекта, а затем за долю секунды вставить их в любое окно или открыть нужный файл.

---

## Сетевая гигиена и приватность

Утилита спроектирована по принципу **абсолютной локальности (Zero Network Footprint)**:
* **Никакого выхода в сеть:** программа не содержит сетевых библиотек, не отправляет запросы на внешние серверы и не проверяет обновления в фоне.
* **Отсутствие телеметрии:** никакой сбор, анализ или передача пользовательских данных, нажатий клавиш и содержимого буфера обмена не ведутся.
* **Все данные только у вас:** локальная база SQLite (`notes.db`), файл конфигурации (`config.json`) и языковые пакеты хранятся исключительно на вашем диске.

## Особенности утилиты

* **Мгновенный захват текста, файлов и папок**
  * **Для текста и кода:** выделите любой фрагмент мышью — он автоматически попадает в буфер обмена (можно сразу нажать `Ctrl + V` без лишних кликов), а рядом с курсором появляется пульсирующий маячок. Нажмите на него, чтобы сохранить запись в группу и задать важность от 1 до 5 звезд.
  * **Для файлов и папок (быстрый серфинг по проекту):** выделите файл или папку в Проводнике и слегка потяните вправо (зажав левую кнопку мыши без `Ctrl` и `Shift`) — появится маячок сохранения. Поддерживаются пакетное выделение и любые спецсимволы в именах (`[ ]`, пробелы, кириллица).
* **Раздельный каталог внутри каждой группы**
  Группы оформлены в виде компактного аккордеона со счетчиком элементов: сверху располагаются текстовые сниппеты со звездным рейтингом, а ниже — аккуратный список сохраненных папок и файлов с кнопками мгновенного открытия в системе, копирования пути или удаления.
* **Умная сортировка и защита от дубликатов**
  * Позиция заметки в списке рассчитывается по комбинированному весу: **важность (звезды) + частота использования**. Самые нужные команды всегда наверху.
  * При повторном сохранении уже существующего текста дубликат не создается — счетчик использования растет, а рейтинг звезд автоматически обновляется в большую сторону.
* **Быстрая вставка в курсор и гибкие комбинации**
  Нажмите заданное сочетание (по умолчанию `Alt + V` или настроенную связку вроде `Shift + ЛКМ` / `Ctrl + ЛКМ`), найдите запись через живой поиск и вставьте ее прямо в активный текстовый курсор. Перехват привязан к аппаратным скан-кодам клавиш и работает одинаково четко на русской и английской раскладках.
* **Работа с длинными заметками и редактирование на лету**
  Клик по названию группы или строке заметки позволяет отредактировать текст прямо в карточке. Длинные многострочные фрагменты можно развернуть кнопкой в карточке, чтобы скопировать отдельную строку, и свернуть обратно.
* **Память окон и поддержка двух мониторов**
  Каждое диалоговое окно при первом открытии появляется по центру активного монитора (где находится курсор), а после перемещения или изменения размера запоминает свои координаты и габариты в `config.json`.
* **Резервное копирование и экспорт**
  При каждом изменении база `notes.db` тихо дублируется в указанную резервную папку (например, на другой физический диск). Экспорт всех заметок в текстовый файл (`all_notes_ГГГГ_ММ_ДД_ЧЧ-ММ.txt` в кодировке UTF-8 с группировкой без повторов заголовков) также автоматически создает копию в резервной папке.
* **Мультиязычность (`RU` / `EN` / `ZH` + свои переводы)**
  Интерфейс переводится через внешние `.ini` файлы в папке `locales/`. Можно в любой момент открыть папку переводов из меню трея и добавить свой языковой файл.

## Установка и запуск

1. [Скачайте](https://github.com/EuSPb24/AINotes/releases/download/notes/AINotes_Setup_1.3.0.exe) **`AINotes_Setup_1.3.0.exe`** (прямая загрузка) или выберите нужную версию на странице [Releases](https://github.com/EuSPb24/AINotes/releases).
2. Запустите установщик (установка дополнительных библиотек или Python не требуется). На этапе настройки укажите основную папку для базы заметок и, при желании, резервную папку на другом диске.
3. Утилита появится в системном трее Windows: зеленая иконка **N** — перехват активен, красная **N** — пауза (переключается кликом по иконке).

## Управление и горячие клавиши

| Действие | Управление |
| :--- | :--- |
| Захватить текст / код | Выделить фрагмент левой кнопкой мыши (сразу копируется в буфер + появляется маячок) |
| Захватить файл или папку | Выделить объект в Проводнике и слегка потянуть вправо зажатой ЛКМ (без `Ctrl`/`Shift`) |
| Открыть окно вставки заметок | `Alt + V` (по умолчанию) или своя комбинация из настроек (например, `Shift + ЛКМ`) |
| Включить / поставить на паузу перехват | Клик левой кнопкой мыши по иконке **N** в системном трее |
| Отредактировать группу или заметку | Кликнуть по тексту в карточке, изменить и нажать `Enter` (или увести фокус) |
